# Desarrollo de un Robot RoboSoccer

## Información general

**Universidad:** Universidad Tecnológica de Querétaro (UTEQ)

**Materia:** Sistemas Embebidos

**Grupo:** LIME002

## Descripción del proyecto

El proyecto consiste en el diseño y desarrollo de un robot RoboSoccer mediante el uso de un microcontrolador STM32. Se trabajará en la integración de los sistemas electrónicos, la programación, el control de motores y la estructura mecánica para lograr el funcionamiento del robot.

## Objetivo

Diseñar e implementar un robot controlado mediante un microcontrolador STM32, integrando hardware y software para controlar sus movimientos y funciones.
